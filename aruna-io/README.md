# Aruna.io static site archive

Static HTML snapshot created from the public aruna.io website on 12 August 2026.

## Open locally

Open `index.html` in a web browser. Internal navigation has been rewritten to the included `.html` files.

The pages remain visually faithful to the source and load the original site's images, fonts, and supporting assets from their public content-delivery URLs, so an internet connection is required for full styling and imagery.

## Included pages

- Home
- About Her Majesty
- Sovereignties
- UK: Queen & Counsel
- USA: Queen and Counsel
- Tarousha Santosh
- The Queen's Endeavours
- Contact

The contact form is preserved visually, but form processing remains dependent on the original provider and is not a standalone local backend.
